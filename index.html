Install blocked?

Google blocks this on purpose.
Here is the fix.

Per Google Play Protect, apps installed from a browser that declare Accessibility are automatically blocked to prevent financial fraud. Kaivor needs Accessibility to control your phone — so the block is expected, not a broken APK.

Recommended

Method A — Pause Play Protect (on phone)

  1. If you installed Kaivor before, uninstall the old version first (Settings → Apps → Kaivor → Uninstall)
  2. Open Google Play Store → profile icon → Play Protect
  3. Tap the gear icon → turn OFF “Scan apps with Play Protect”
  4. Download and open Kaivor-v1.0.apk from Files — not Chrome’s download notification
  5. Tap Install → when done, turn Play Protect scanning back ON

Method B — Install from PC (ADB)

USB debugging on, then run from the repo:

adb install -r downloads/Kaivor-v1.0.apk

Or use scripts/install-kaivor.ps1 on Windows.
