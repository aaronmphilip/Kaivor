Architecture

Fast path first. Vision when the screen demands it.

Kaivor starts with the Android accessibility tree for speed, then activates visual screen reading for sparse UIs, documents, form recovery, and anything the tree cannot explain.

  • Progress in the notch overlay and persistent notification.
  • Gemini powers reasoning, voice, and document understanding.
  • Voice notes become commands through on-device STT.
  • Blocked tasks surface exact questions in Telegram.

Principle

Quiet interface.
Relentless execution.

One command. Visible state. Precise questions when details are missing. A final report when the Android task is complete.
